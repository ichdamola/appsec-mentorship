# Week 14: Security Misconfiguration & Vulnerable Components

## 🎯 What you'll learn

The boring bugs that hit production hardest — default credentials, exposed admin panels, unpatched dependencies.

By the end of this week you'll be able to:
- Default credentials and unchanged setup wizards
- Verbose error messages leaking stack traces
- Outdated dependencies (Log4Shell, Spring4Shell)
- SBOM and SCA tooling (Dependabot, Trivy, Snyk)
