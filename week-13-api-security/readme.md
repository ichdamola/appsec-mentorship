# Week 13: API Security (REST + GraphQL)

## 🎯 What you'll learn

The bug classes specific to APIs: BOLA/IDOR at scale, broken object-property authorization, mass assignment, GraphQL introspection and query depth.

By the end of this week you'll be able to:
- BOLA (Broken Object-Level Authorization)
- Mass assignment (extra fields → privilege escalation)
- Rate limiting (or its absence)
- GraphQL: introspection, depth limits, batched query abuse
