# Week 02: Sessions, Cookies, and JWTs

## 🎯 What you'll learn

Cookies, session tokens, JWTs — how the web identifies returning users, and how each scheme breaks.

By the end of this week you'll be able to:
- Cookie security flags (HttpOnly, Secure, SameSite)
- Session fixation and token rotation
- JWT signature stripping ('alg: none')
- Session timeout and revocation
